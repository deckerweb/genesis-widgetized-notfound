# Help and security

[English](Help-and-security) · [Deutsch](Hilfe-und-Sicherheit)

For questions and reproducible bugs, use [Issues](https://github.com/deckerweb/genesis-widgetized-notfound/issues). Use [Discussions](https://github.com/deckerweb/genesis-widgetized-notfound/discussions) for general questions and examples. Include plugin, WordPress, PHP and Genesis versions; omit passwords and private site data.

Report vulnerabilities privately using [GitHub Security Advisories](https://github.com/deckerweb/genesis-widgetized-notfound/security/advisories/new), following the [security policy](https://github.com/deckerweb/genesis-widgetized-notfound/blob/master/SECURITY.md). Do not post security issues publicly. This also covers the embedded Library and Updater.
